# Merchant study kit

Anyone on the team can help recruit and run sessions. Target: 3–5 merchants who sell in drops today. Recruitment runs 5–18 Oct;
sessions 26 Oct – 8 Nov, once the console is usable in `staging`.

| File | Use |
| --- | --- |
| [`outreach.md`](outreach.md) | First message (Instagram / Telegram DM, email) and follow-up |
| [`session-script.md`](session-script.md) | 45-minute session: consent, three tasks, SUS, interview |
| [`sus.md`](sus.md) | System Usability Scale form and scoring |
| [`tracker.csv`](tracker.csv) | Who was contacted, status, session date |

What the report needs from this study: time to first drop unaided, errors and hesitation points per task,
an SUS score per merchant, and quotes on current practice and on whether the price is credible.
